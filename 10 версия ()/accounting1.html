Как это работает:

✅ Автовыбор папки - система пытается найти файл pazl-config.json в нескольких местах

✅ Ручной выбор - выбрать папку через системный диалог

✅ Сохранение пути - путь сохраняется в JSON файл для использования в будущем

🔄 Места поиска конфига:

  • Папка с приложением (рядом с HTML файлом)
  • Папка "Загрузки"
  • LocalStorage (как запасной вариант)
